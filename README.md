Este projeto consiste no desenvolvimento de uma aplicação de calculadora, criada com o objetivo de praticar e aprimorar conhecimentos em programação e desenvolvimento de software.

A aplicação permite realizar operações matemáticas básicas, como adição, subtração, multiplicação e divisão, utilizando uma interface simples e intuitiva.

O projeto faz parte do meu processo de aprendizado na área de Tecnologia da Informação, contribuindo para o desenvolvimento das minhas habilidades em lógica de programação, criação de interfaces e organização de código.

Este projeto também representa uma etapa da minha evolução como estudante de Análise e Desenvolvimento de Sistemas, colocando em prática conhecimentos adquiridos durante os estudos.
